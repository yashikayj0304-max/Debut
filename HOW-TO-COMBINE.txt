Debut — part 2 of 3

This is one third of the app. It does NOT run on its own.

1. Unzip all three: debut-part1.zip, debut-part2.zip, debut-part3.zip
2. Put the contents of all three INTO THE SAME FOLDER (merge, do not replace).
3. You should end up with one folder containing:
      app.py, views.py, requirements.txt, Procfile, render.yaml, Dockerfile
      static/   templates/part1/   templates/part2/   tests/   docs/
4. Push that folder to GitHub, then point Render at the repo.

Each part is under 80 files, so every upload stays below GitHub's 100-file limit.
All three parts are needed; the app will not start if any is missing.
