Debut — part 1 of 2

This is half of the app. It does NOT run on its own.

1. Unzip debut-part1.zip
2. Unzip debut-part2.zip INTO THE SAME FOLDER (merge, don't replace)
3. You should end up with one folder containing:
      app.py, views.py, requirements.txt, Procfile, render.yaml
      static/            templates/part1/   templates/part2/
      tests/             docs/
4. Upload that folder to GitHub, then point Render at the repo.

Part 1 has: all the Python code, static files, templates/part1, and the deploy files.
Part 2 has: templates/part2, tests, and docs.

Both halves are needed. The app will not start without templates/part2.
